关于本手册

「提瓦特旅人图鉴」是一款 纯前端同人作品（HTML + CSS + JS，无框架、可完全离线运行），用于角色介绍与互动。页面布局参考原神官网思路，视觉与交互均为原创设计。

素材说明：角色头像、祈愿立绘、名片背景、中文语音、背景音乐（官方 OST）均下载自公开网络资源，仅用于个人学习与欣赏，原神角色形象与版权归米哈游 miHoYo 所有。

交互小贴士：点击「开启旅程」后播放主题曲；进入不同国度会自动切换当地 OST 与主题色；点击任意角色卡可查看详细档案、欣赏立绘与名片，并聆听官方中文语音；按 / 全局搜索、M 切换音乐、Esc 关闭弹窗、←→ 切换角色；连续点击右下角派蒙有彩蛋。
